# Regression

回归用例回答一个问题：**修完这个 Bug，旧功能还通过吗？**

约定：

- 每个被修复的缺陷，至少留下两条日志/数据：`*_before`（复现）与 `*_after`（修复后）。
- 修复后必须重跑全部 `layer in (compile, static, log, algorithm, regression)` 的用例。
- 若某条旧用例因为新行为而失败，必须明确是"断言过时"还是"真的回归"，
  前者单独提交并更新断言，后者视为回归缺陷。
